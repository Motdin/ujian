1. KARTU IDENTITAS HALAMAN (ini yang divideo)

URL ASLI   : …
ORIGIN ASLI : …
REFERRER   : …
UA         : …

Jika aplikasi wallet membuka halaman ini tetapi bar URL / judul app menampilkan domain ATAU nama lain (mis. "PancakeSwap") → temuan origin-spoof. Video: buka halaman ini via deep-link, zoom bar URL app, lalu zoom kartu ini.

2. PELUNCUR DEEP-LINK (ganti {URL} otomatis jadi halaman ini)

Isi template skema → tekan BUKA. Kalau satu skema gagal, catat, lanjut ke bawah. Uji dari KONTEKS LUAR browser juga (kirim link via email/WA ke dirimu sendiri, buka dari sana) — trigger dari luar adalah kondisi terkuat.

3. CONTOH "JEBAKAN LABEL" (halaman target bertema palsu)

Untuk membuktikan dampak: buat salinan file ini di host-mu dengan path bertema (gunakan nama netral milikmu, JANGAN brand orang lain di DOMENU) lalu bandingkan: apa yang ditampilkan app vs origin sebenarnya. Cukup tunjukkan mismatch label.
